# SimplyLingua Online Academy

A complete A2 CEFR English course for adult learners, built with HTML/CSS/JS.

## Course Structure

| File | Unit | Grammar Focus |
|------|------|--------------|
| index.html | Homepage | — |
| unit1.html | Who I Am | Verb to be |
| unit2.html | A Busy Life | Present simple |
| unit3.html | Shopping & Money | can/can't, prices |
| unit4.html | My Neighbourhood | there is/there are, prepositions |
| unit5.html | Food & Health | like/don't like, countable/uncountable |
| unit6.html | Getting Around | Present continuous |
| unit7.html | Work & Plans | going to (future) |
| unit8.html | Looking Back | Past simple |

## Adding Media

- **Images**: place `word.jpg` files in `images/unitN/` (e.g. `images/unit1/nurse.jpg`)
- **Audio**: place ElevenLabs MP3s as `images/unitN/story.mp3` (e.g. `audio/unit1/story.mp3`)

If files are missing, the page falls back to emoji placeholders and Web Speech API.

## Deployment

Hosted on Netlify — auto-deploys on every push to `main`.
